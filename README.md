# 🌀 Околесица

Игра для компании друзей: смесь испорченного телефона, «Мемни это» и Алиас.
Играть можно каждому со своего компьютера — сайт не требует сервера, бэкенда
или регистрации: соединение между игроками идёт напрямую по WebRTC (P2P).

## Как это работает

1. Первый игрок жмёт «Создать комнату» — получает короткий код (например `X7QP`).
2. Скидывает код (или ссылку `?room=X7QP`, кнопка «Скопировать ссылку») друзьям.
3. Остальные жмут «Войти», вводят код и имя.
4. Как только собралось от 3 до 8 человек — хост жмёт «Начать игру».

### Правила партии

Каждый игрок ведёт свою «книгу». Книги по кругу переходят от игрока к игроку,
и каждый раз происходит одно из трёх:

- **Фраза** — пишешь смешную фразу или ситуацию (если это начало книги),
  либо описываешь одной фразой мем, который тебе показали (не видя оригинала —
  это и есть момент а-ля Алиас, когда угадываешь вслепую).
- **Рисунок** — рисуешь мышкой/пальцем фразу от предыдущего игрока.
- **Мем** — берёшь чужой рисунок и добавляешь к нему смешную подпись сверху/снизу.

Когда круг заканчивается, начинается **показ историй**: по очереди видно,
во что превратилась каждая книга от первой фразы до последнего шага —
обычно это выглядит как полная дичь. Можно закидывать реакциями (эмодзи
всплывают у всех на экране). В конце — голосование за самую смешную историю
и подиум.

Хост в лобби настраивает время на каждый тип раунда. После игры можно сразу
сыграть ещё раз с теми же друзьями — истории каждый раз получаются разные.

## Как выложить на GitHub Pages

1. Создай новый репозиторий на GitHub, залей туда три файла:
   `index.html`, `style.css`, `app.js` (и это README, если хочешь).
2. Зайди в **Settings → Pages**, в разделе **Source** выбери ветку `main`
   и папку `/ (root)`, сохрани.
3. Через минуту-две сайт появится по адресу вида
   `https://ТВОЙ_НИК.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/`.
4. Кидай эту ссылку друзьям — играть можно прямо в браузере, ничего
   устанавливать не нужно.

Никакого сервера или базы данных не требуется: игра использует бесплатный
публичный сигнальный сервер PeerJS только для установки соединения, а дальше
все данные (фразы, рисунки, голоса) идут напрямую между браузерами игроков.

## Технические детали и ограничения

- Один из игроков («хост», тот, кто создал комнату) держит состояние партии.
  Если хост закроет вкладку посреди игры — партия прервётся. Обычным игрокам
  разрыв связи не страшен: они автоматически выбывают из текущего раунда
  (за них подставляется заглушка), игра продолжается.
- Обновление страницы = выход из комнаты. Просто держите вкладку открытой
  весь вечер.
- Рисунки передаются как векторные штрихи (не картинки), поэтому всё летает
  быстро даже на слабом интернете.
- Рекомендуемый состав: 3–8 человек. Больше 8 в одной P2P-комнате уже не так
  стабильно — используемый бесплатный сигнальный сервер PeerJS не рассчитан
  на большие комнаты.

Приятного вечера! 🎉
